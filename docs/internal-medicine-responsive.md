# 내과 반응형 작업

## 적용 범위

- 대상: `/internal-medicine`, Webflow 페이지 `69d74a8ea2cac3ea9cfed34d`.
- 기준 화면: 1440px 이상은 기존 Webflow 스타일 유지.
- 768–1439px: 좌우 여백을 연속적으로 줄여 콘텐츠 폭을 확보한다. 인트로와 러닝 메이트의 글/사진 구도, 통찰의 두 원, 프로세스의 좌우 흐름, 진료 영역의 2열 배치를 유지한다.
- 768–1039px: 인트로 문구의 들여쓰기와 크기를 조정하고, 프로세스 영문 부제를 제목 아래로 보내 본문과 겹치지 않도록 한다.
- 767px 이하는 기존 레이아웃을 유지한다. 아래 구간은 별도의 세로 설계가 필요하다.

## 세로 설계가 필요한 구간

| 구간 | 현재 상태 / 다음 작업 |
| --- | --- |
| 첫 화면 인트로 | 사진과 문구가 같은 배경 위에 놓인다. 휴대폰에서는 사진 영역, 제목/필기체 위치, 본문 폭을 함께 설계해야 한다. |
| 심도 있는 통찰 | 본문과 두 원의 세로 연결, 원 사이 간격과 텍스트 폭을 함께 정해야 한다. 기존 원형 인터랙션과 세로 전환 규칙은 유지했다. |
| 러닝 메이트 | 글이 2열 중 왼쪽에 남아 휴대폰에서 좁게 접힌다. 사진과 글을 위아래로 나누고 세로용 사진 크롭을 정해야 한다. |
| 진료 프로세스 | Step 1–4와 Step 5를 잇는 곡선이 가로 흐름을 전제로 한다. 휴대폰용 진행 순서와 되돌아오는 연결선을 별도로 설계해야 한다. |
| 진료 영역 카드 | 479px 이하에서 중간 `.white-frame_connect` 섹션이 기존 Webflow 규칙으로 숨겨져 03 소화기·간담도와 04 신경·면역 카드가 빠진다. 6개 카드의 세로 간격과 배경 일러스트 구도를 정하면서 해당 섹션의 표시도 함께 수정해야 한다. 이번 작업에서는 숨김/표시 규칙을 변경하지 않았다. |

## 구현 및 검증

- 기존에 등록된 `internal-medicine/bootstrap.js`에 `#hx-im-responsive-style`을 추가했다. 새 CSS 파일과 로더 목록 변경은 없다.
- 규칙은 내과 페이지 ID 및 768–1439px에 한정한다. 공용 스타일, 정식 도메인 접근 제한, 측정, 원형/프로세스 애니메이션은 수정하지 않는다.
- 검증 폭: 1920, 1440, 1439, 1280, 1040, 1039, 992, 991, 834, 768, 767, 479, 390px.
- 브라우저 검증은 발행된 스테이징 HTML에 수정한 로더를 대입해 수행한다. GSAP은 같은 3.12.2 버전을 검증 브라우저에 제공했다. 네트워크 정책상 Adobe Fonts는 불러오지 못하므로 해당 서체의 최종 줄바꿈은 실제 사용자 브라우저에서 추가 확인이 필요하다.
- 일반 변경이므로 staging에만 반영하며 main 승격은 별도 사용자 지시 후 진행한다.
