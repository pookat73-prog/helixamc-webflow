# 코드 기반 인증 상세 모달

2026-10-22 사용자 승인: 인증 상세를 의료진과 같은 코드 기반 창으로 전환하고, 기존 Webflow 인증 상세 페이지는 사용자가 이후 삭제한다. staging 검토를 마쳤으며, 2026-10-23 사용자가 “운영ㄱㄱ~”로 운영 반영을 승인했다.

## 구현

- 기존 로더에 등록된 `about/cert-modal/modal.js`와 `modal.css`를 교체한다. 신규 런타임 파일이나 라이브러리 없음.
- `modal.js`의 DATA가 인증 원문과 마크 이미지의 단일 편집 지점이다. 2026-10-22 운영 게시본의 문구를 보존했다. `scripts/fixtures/cert-modal/source.json`은 이관 전 원문의 검증용 기록이며 런타임에서 읽지 않는다. 기존 빈 placeholder 그림은 이관하지 않았다.
- 인증 3종의 표지와 기존 슬라이드 순서(AAHA 4장, VECCS 4장, CFC GOLD 3장)를 유지한다. 흰색 720px 폭·720px 기준 고정 높이 패널을 사용하고, 화면 높이에 맞춰 제한한다. 첫 장은 제목 → 마크 → 설명을 최대 500px의 왼쪽 정렬 한 열로 쌓고, 다음 장부터 배너·스크롤 본문을 표시한다. 하단 조작부와 창 크기는 유지한다.
- 내용 표시를 위해 Webflow 상세 HTML, iframe, fetch, Webflow 클래스나 CSS를 사용하지 않는다. AAHA 마크와 병원 로고는 기존 Webflow 자산 CDN에서 불러온다. 응급·고양이 마크는 `about/cert-modal/assets/`의 날짜를 가린 사본을 모듈과 같은 커밋에서 불러온다. 원본 자산은 보존하며, 페이지 삭제 시 자산은 삭제하지 않는다.
- 카드별 클래스에 맞춰 기존 + 링크를 URL로 재연결한다. Webflow에서 페이지 삭제 후 Link prop이 비어도 기존 a 요소를 찾아 재연결한다. 모바일 배지는 기존 배치와 클래스 유지.
- 일반 클릭은 현재 문서를 유지하고 History API로 인증 선택 주소를 기록한다. Ctrl/Command 클릭은 새 탭에서 같은 창을 연다. 직접 접속·새로고침·뒤로/앞으로·닫기·ESC·배경 닫기, 포커스와 스크롤 복원을 지원한다.
- 공유 주소가 소개페이지 내부 선택값이므로 별도의 정적 상세 HTML이나 인증별 검색 페이지는 생성하지 않는다. canonical은 소개페이지 주소를 유지한다. 소개페이지를 삭제하면 동작하지 않는다.
- 기존 cert_modal_open_desktop/mobile, cert_modal_slide/read/close의 인증 값은 이전 경로를 유지한다. 공유 주소 직접 로드/뒤로·앞으로 이동에는 새 열기 클릭을 집계하지 않는다. 공통 측정 모듈과 스테이징·운영자 제외 규칙을 따른다.

## 공유 주소와 기존 페이지 삭제

| 기존 경로 | 새 공유 주소 |
|---|---|
| `/aaha-cert` | `/discover-helix?cert=aaha#cert` |
| `/emergency-cert` | `/discover-helix?cert=emergency#cert` |
| `/cat-cert` | `/discover-helix?cert=cat#cert` |

1. staging 자산 도달과 인증 3종의 동작을 확인한다.
2. 사용자가 승인한 뒤 이번 변경만 main에 반영하고 운영 사이트의 동작과 자산 버전을 확인한다. staging 전체를 무조건 main으로 합치지 않는다.
3. **그 다음 사용자에게 기존 인증 상세 3페이지의 삭제 가능 여부를 안내한다.** 소개페이지(`/discover-helix`)와 인증 이미지 자산은 유지한다. 이 작업은 페이지를 삭제하지 않는다.
4. 기존 상세 주소는 페이지가 존재하고 새 모듈이 로드되는 동안 새 주소로 이동한다. **페이지 삭제 후 과거 공유/검색 주소까지 유지하려면 위 표의 301 리디렉션을 Webflow 사이트 설정에서 등록하고 게시해야 한다.** 이 사이트는 비 Enterprise이므로 연결된 API의 redirect 기능이 거부되었다. API로 리디렉션을 저장했다고 간주하지 않는다.
5. 코드/CDN 변경만으로 About 로더에 적용되므로 이 변경 자체는 Webflow 페이지 쓰기나 Publish가 필요 없다. main은 사용자 승인 전 변경하지 않는다.
