## 4. Work에서 확인할 순서

1. **실제 검증 대상부터 확인해 주세요.** 원본과 첨부 후보 CSS를 같은 HTML·생성 CSS·글꼴·사진 조건에서 비교할 수 있는 격리 미리보기 또는 실제 후보 URL을 사용해 주세요. 후보 CSS가 실제 적용됐는지 본문 해시와 계산값을 확인해 주세요. CSS 대입/후보 URL에 접근할 수 없다면 첨부 이미지 검토와 공개 원본 확인까지만 진행하고, 후보 미적용 상태를 통과로 표시하지 마세요. 이를 해결하려고 공개 staging 설정이나 운영 사이트를 바꾸지 마세요.
2. 실제 페이지를 열기 전에 분석·광고·행동 로그 전송 차단을 설정하고 실제 차단 여부를 확인해 주세요. 예약 제출·통화·외부 메시지는 하지 마세요.
