## D02 — 하나의 label root 조사

선택 후보는 `.hx-fcta-form .hx-fcta-form__label`이다. [공통 생산자](../../global/floating-cta.js)는 이름·연락처·메모 label 세 개와 이름/연락처의 필수 표시 span을 만든다. 게시 문구는 ‘이름 *’, ‘연락처 *’, ‘메모 (선택 · 최대 20자)’다. 이는 실제 사용을 의도한 생산자 소스 확인이며, 현재 공개 DOM에서 렌더링된 개수를 측정한 것은 아니다.

[전역 정책](../../global/word-wrap.css)은 body와 모든 자손에 `word-break:keep-all`, `overflow-wrap:normal !important`를 적용한다. label의 컴포넌트 규칙은 폰트·색상을 소유하고 emergency wrap 예외는 없다. 따라서 긴 비분리 토큰을 조사할 근거는 있으나 **실제 넘침이나 책임 충돌은 아직 입증하지 못했다.** 폼 전체 예외나 전역 정책 철회는 하지 않는다.

기존 내과 목록/제목, form intro, consent body는 제외한다. `.hx-fcta-form__guide`와 labelrow는 선택한 현재 생산자에서 생성 근거를 찾지 못해 후보에서 제외했다. 모든 페이지나 역사적 DOM에 없다고 단정하거나 CSS를 삭제하지 않는다.

환경 복구 후 필요한 하나의 실행 단위:

1. 현재 고정 입력을 그대로 재생하고 실제 label과 for/input 연결·필수 span·공통 스타일 채택을 확인한다. 정상 게시 문구의 glyph·폰트·높이·배치를 먼저 보존한다.
2. 한글·영문·URL·숫자의 긴 합성 입력을 label 직접 텍스트와 span/a 자손으로 구분해 넣고 복구한다. 긴 문자열은 게시 문구나 실제 이용자 입력으로 보고하지 않는다. glyph 범위와 자손 bounds가 root·폼·viewport 밖으로 나가는지 검사한다. label 안에 label을 중첩하는 잘못된 HTML fixture는 만들지 않는다.
3. 원본 넘침이 입증된 경우만 이 root의 책임을 국소 수정한다. 기존 global keep-all과 다른 root의 계산값을 보존하고 늦은 전역 CSS 삽입도 통제한다. 원본이 정상이면 수정하지 않는다.
4. 홈/소개/services/FAQ/내과 ×1440/820/390의 15쌍에서 게시 문구·실제 폰트·높이·배치·링크·폼 입력/개인정보 토글·열기/닫기·스크롤을 확인한다. 관련 경계와 기존 intro/consent/내과 예외도 보존한다. 실제 제출·통화·분석 전송은 차단한다.

## D05 — 하나의 실제 문구 속성 후보

선택한 생산자의 전화 CTA에는 `.hx-fcta-phone-btn__copy > .hx-fcta-call-btn__text` span이 있다. 조사 후보는 이 문구의 `font-weight`다. CTA CSS의 전화 문구 규칙은 앞부분에 700, 뒤의 반복 규칙과 최종 nested label 공용 규칙에는 600을 선언한다. [CSS](../../global/floating-cta.css)의 약836/926/967/1049 주변을 확인했다. 이는 후행 무효화의 **정적 후보**이며 의도적인 typography 보완일 수 있다. 계산된 최종 소유자·통제 편집 무효화·제품 결함을 확인했다고 하지 않는다.

전화 보조 문구 `.hx-fcta-phone-btn__subtext`는 이 생산자에 생성되지 않는다. 새 조사 대상으로 채택하지 않지만 legacy/다른 생산자의 소비까지 배제한 것이 아니므로 삭제하지 않는다. 다른 작업자의 파일 마지막 전화 정렬 블록도 그대로 보존한다.

기존 CTA 높이·폭·장식·간격·테두리 색상은 재수정하지 않는다. 후보 하나의 원본 통제 편집이 실제 문구에 도달하지 않는지 먼저 입증하고, 정상 variant override인지 책임 충돌인지 구분한다. 소유자 변경은 원하는 한 요소에만 도달해야 하며 다른 form/버튼/인접 요소를 바꾸지 않아야 한다. 같은 CSS 파일이므로 D02 제품 변경이 생기면 순차 처리하고 각 단위만 역적용 가능한 구성을 유지한다.

필수 비교 폭은 320/359/360/361/390/479/480/766/767/768/820/990/991/992/1279/1280/1440/1920이다. 기존 6모드는 기본, mobile-bar, overlap-fix, overlap-fix+home, mobile-bar+overlap-fix, legacy다. 기존 도구와 같은 **108쌍 계산 CSS·geometry·PNG 및 36조건 통제 편집**을 유지한다. 실제 생산자 DOM과 legacy 호환 fixture를 구분하고, 합성 fixture만으로 현재 공개 소비가 있다고 하지 않는다. 이번에는 이 비교를 실행하지 못했다.
