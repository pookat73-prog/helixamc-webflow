- 기존 Local Chrome 재시도 없이 관리형 Cloud Chromium 151.0.7922.173을 사용했다. localhost 서버 없이 가상 webflow.io 주소를 탐색 전에 가로채 합성 문서·로컬 JS를 제공했다. Service Worker와 WebSocket을 별도로 차단했다.
- 브라우저와 자식 프로세스에 커널 seccomp 차단을 적용했다. 비UNIX 소켓 및 io_uring 거부, 상속된 Internet 소켓이 있으면 실행 중단을 대조했다. 예약되지 않은 invalid 도메인만 사용한 독립 차단 대조에서 비UNIX 소켓 11회 모두 거부, Internet 주소 connect/send 0회였다. 실제 앱의 전송 0건 판정에 이 결과를 합산하지 않는다.
- 최초 합성 실행의 syscall 로그 파서 실패를 보존했다. 분리 출력 연결을 수정한 검사기의 새 단일 실행으로 인프라 검사를 통과했다. 제품 변경이나 검사 기준 완화는 없다.
