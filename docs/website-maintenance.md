## 게시 전후 기록

1. 게시 대상과 현재 실제 자산, 배포 후보, 변경 범위 및 원복 자료의 대응을 확인한다.
2. CDN 응답 및 자산 해시를 확인하고 [Site Quality Checks](../.github/workflows/site-quality.yml)와 영향 기능의 기존 검사 결과를 대조한다.
3. 게시 범위와 원복 가능성을 수동으로 검토한다. GitHub 검사와 별개로 Webflow 게시 승인 범위를 확인한다.
4. 승인된 대상만 게시한 뒤 공개 HTML, 실제 응답·로더, 영향받는 동작을 확인한다. 검증 결과에 실행환경과 미확인 범위를 명시한다.
5. 원복은 변경 범위에 맞춰 승인된 항목과 묶인 조합만 되돌린다. 이전 자산과 동작을 게시 직후 확인한다.
