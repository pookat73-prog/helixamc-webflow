# 의료진 고유 주소 운영 반영

2026-10-21 사용자 “정식 올리고 seo 작업 진행해줘”로 운영 게시와 Search Console 제출을 승인했다.

- 스테이징에서 검토한 의료진 모달+고유 주소 기능만 현재 main 위에 반영한다. staging 전체 병합은 하지 않는다.
- 현재 main의 의료진 읽기/닫기 측정과 다른 페이지 측정은 보존한다. 일산 계측 수정은 이 릴리스에 추가하지 않는다.
- 26명의 정적 본문·고유 제목·대표 주소·기존 검색 가능한 링크를 유지하고 스테이징 검토용 noindex/nofollow를 제거한다. canonical은 기존 사이트의 https://helix-amc.com 기준을 유지하되 실제 리디렉션은 네트워크 차단으로 미확인이다.
- Webflow 사이트맵 포함 설정은 26명 전원 true다. 실제 robots.txt/sitemap.xml과 HTTP 200/404는 작업 환경 proxy CONNECT 403으로 미검증이다. API robots 조회도 Enterprise 요금제 제한으로 불가하다. 이 때문에 요금제를 변경하지 않는다.
- 운영 병합본 로컬 검증: 전체 26명 최초 HTML 본문·제목·canonical·404, 1440px/390px에서 기존 24명 카드/모달·직접 접속·새 탭·새로고침·닫기·포커스·뒤로/앞으로 및 클릭 이벤트 중복 없음. 13개 기존 측정 검사와 8개 사이트 품질 검사 통과. 실제 분석 전송은 mock 처리했다.
- 현재 연결 도구에는 Search Console 제출 기능이 없고 Windsor 연결도 GA4 계정뿐이다. 인증 정보나 브라우저 제어 연결 없이 제출했다고 보고하지 않는다. 제출·실제 색인 생성·검색 노출/클릭은 각각 별도로 확인한다.

게시 결과는 이 문서와 배포 매핑에 후속 기록한다. 전역 사이트 분석 head, 의료진 데이터, unrelated Webflow 페이지 설정은 변경하지 않는다.
